## 4. Milestone 6 Code Changes Review

Inspected the exact diff between the pre-audit backup (`.backup_milestone6_20261027_051400`) and the active workspace:

### 1. `server.js` Modifications
1. **Configurable Data JSON Path (Line 35):**
   - *Diff:* `const ROOT = __dirname, STORE = process.env.DATA_JSON_PATH ? path.resolve(process.env.DATA_JSON_PATH) : path.join(ROOT, 'data.json');`
   - *Verification:* Prevents isolated environments (e.g., Staging) from polluting or reading the root `data.json`.
2. **Request Body Parser Limit & Stream Drain (Lines 151–172):**
   - *Diff:* Added `let exceeded = false;` flag, `req.pause();`, and immediate error emission `reject(new Error('Payload too large'))`.
   - *Verification:* When a request exceeds 1MB, the stream is paused, the error is caught by the router, and the server responds with HTTP `413 Payload Too Large` and header `'Connection': 'close'`. This cleanly terminates the TCP connection and prevents unhandled socket leaks or hanging clients.
3. **Query String Token Hardening (Lines 243–265):**
   - *Diff:* Restricted query string token parsing in `auth(req)` strictly to `/api/events` (required for native browser `EventSource`). Completely removed query token parsing from `authAdmin(req)`.
   - *Verification:* Protects session tokens from exposure in proxy access logs and browser history (CWE-598).
4. **Global Security Response Headers (Lines 485–492):**
   - *Diff:* Invokes `applySecurityHeaders(res)` at the start of `route(req, res)`.
   - *Verification:* Guarantees `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `X-XSS-Protection: 1; mode=block`, and `Referrer-Policy: strict-origin-when-cross-origin` on all API responses.
5. **Payment Gateway Underpayment Guards (Lines 1750–1775, 1850–1875):**
   - *Diff:* Added strict amount comparison in PhonePe webhook (`data.amount` vs `tx.amount_paise`) and Paytm webhook (`b.TXNAMOUNT` vs `tx.amount`).
   - *Verification:* An underpayment webhook is rejected with HTTP 400, flagged with `reconciliationStatus: 'flagged_ambiguous'`, and logged in the transaction audit log.
6. **Graceful Shutdown Handlers (Lines 2410–2435):**
   - *Diff:* Added `SIGTERM` and `SIGINT` listeners to invoke `server.close()`, call `persist()`, and cleanly close `sqliteDb`.
   - *Verification:* Guarantees that in-flight requests finish, WAL checkpoints complete, and no stale JSON snapshot can overwrite SQLite data upon container restart.
